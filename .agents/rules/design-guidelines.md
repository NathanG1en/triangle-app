# Triangle App Design Guidelines for Agents

All UI changes in this codebase must adhere to the design system in [docs/DESIGN_GUIDELINES.md](file:///Users/nathanglen/.gemini/antigravity/scratch/triangle-app/docs/DESIGN_GUIDELINES.md).

## Key Directives:
- **Palette**: Warm paper (`#FFFEFD`), deep ink (`#1A1A1A`), surface (`#F5F1EC`), muted (`#77736F`), with subtle accents (`coral` `#D95F4B`, `forest` `#075E59`, `lilac` `#C8C4E8`).
- **Typography**: Serif headlines (editorial display) + Sans-Serif functional UI (buttons, metadata, nav).
- **Social Context**: Always display human attendance text (*"Maya, Chris + 4 going"*) and avatar stacks.
- **Layout**: Varied editorial magazine rhythm (Hero Featured Card, Friend Activity Row, Curated Collections, Feed) instead of generic card grids.
